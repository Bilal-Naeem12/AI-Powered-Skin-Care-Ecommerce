# AI-Powered-Skin-Care
 The purpose of this project is to build an e-commerce application to offer customized skincare through artificial intelligence. Using deep learning and machine learning models, the system recognizes the problems on a user's skin based on photos uploaded by them, for example acne, pigmentation, dark circles, etc. After that it prescribes a perfect morning and evening skincare routine for a particular user’s skin type and problems. To ensure that the products are safe for use, the platform enables users to input allergen information that is matched with the product ingredients to recommend only safe products.
